# src/fs1r: the hardware's values

What the FS1R itself holds or does, as numbers: its fixed values, the EPROM's tables and the constants tuned to match it. **No engine code lives here.** Presets, the engine, the tone generator and the DSP read these; nothing here reads them back.

| File | What | Status |
|---|---|---|
| `hardware.h` | sample rate, channel count, the filtered channels, the CPU clock and the tick rate: the board's own numbers | Matches the FS1R, never tuned |
| `tables.h` | the EPROM's conversion tables (note, velocity, EG, pan, send...) | generated by `tools/extract_tables.py`, do not hand-edit |
| `algorithms.h` | the 88-algorithm routing table | generated by `tools/extract_tables.py`, do not hand-edit |
| `rom_tables.h`, `.cpp` | the filter and effect hosts' EPROM tables (descriptors, LFO and coefficient tables) | generated by `tools/extract_vop3_rom.py`, do not hand-edit |
| `vop3_regs.h` | the DSP register map the hosts write | Matches the FS1R |
| `cal.h` | every tuned constant, each saying what it controls and what its value means | Tuned: **the** file to edit when calibrating |

## Rules
- A value goes here only if the hardware has it. FSVR's own knobs go in `src/engine/tuning.h`.
- A disagreement with the FS1R means the value is wrong, or for `cal.h`, is not yet calibrated.
